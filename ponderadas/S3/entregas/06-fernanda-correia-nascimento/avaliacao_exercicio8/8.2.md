def gerar_tempos_uniforme(objetivo, usou_busca, faixa_horaria):
    """Versão modificada: tempo de leitura com distribuição uniforme em vez de log-normal."""
    params_busca = {
        'buscar_sistema': (4.0, 0.55), 'buscar_documento': (4.0, 0.55),
        'buscar_pessoa': (4.0, 0.55), 'ler_comunicado': (2.9, 0.45),
        'acompanhar_noticias': (3.2, 0.50),
    }
    mu_b, sig_b = params_busca.get(objetivo, (3.5, 0.50))
    tempo_busca = np.random.lognormal(mu_b, sig_b)  # mantemos log-normal na busca

    # *** MODIFICAÇÃO: tempo de leitura agora é uniforme ***
    # Ajuste os limites para manter uma média similar
    lim_inf = 30
    lim_sup = 400 if objetivo in {'ler_comunicado', 'acompanhar_noticias'} else 200
    tempo_leitura = np.random.uniform(lim_inf, lim_sup)

    if not usou_busca:
        tempo_busca *= 0.45
    if faixa_horaria == '08-11':
        tempo_leitura *= 0.88
        tempo_busca   *= 1.08
    ruido = np.random.gamma(shape=2.0, scale=8.0)
    tempo_total = tempo_busca + tempo_leitura + ruido
    return tempo_busca, tempo_leitura, tempo_total

#### **Resposta**

&emsp;A distribuição após a uniformização não tem cauda direita, uma vez que elimina os valores extremos altos que a log-normal produz naturalmente, isso significa que a base modificada parece mais comportada, mas perde o realismo das leituras mais longas de comunicados. A diferença entre grupos (clicou e não clicou) aumenta de +36s na original para +88s na modificada, já que existe uma menor concentração de tempos muito baixos de leitura. Desta forma, a coerência interna melhora, porque a uniforme distribui valores de forma que os extremos superioresficam mais distantes dos inferiores.

&emsp;Avaliando uma possível melhora ou piora da base, pode-se dizer que, apesar de melhorar a coerência interna (onde a diferença das medianas de torna maior), a fidelidade deixa a desejar, passando a não representar o comportamento real de leitura dos usuários do IPT, que segue uma distribuição naturamente não-uniforme, sobretudo pelas poucas sessões muito demoradas de leituras. Os gráficos plotados abaixo deixam claro essas mudanças, com a redução dos ruídos estatísticos e aumento consequente do tempo de leitura médio dos usuários.

&emsp;Em relação a hipótese comportamental do E02, a base original serve melhor para sua preservação, porque mantém padrões mais próximos do comportamento humano real de navegação e leitura. A distribuição log-normal do tempo_leitura_segundos produz assimetria e cauda direita, características esperadas em métricas comportamentais: muitos usuários passam pouco tempo lendo, enquanto poucos permanecem por períodos longos em conteúdos específicos. E desta forma, preserva-se a relação entre as variáveis, como pode-se ver no gráfico, em que a base original mantém uma separação coerente entre os grupos sem perder a dispersão e a cauda longa características do comportamento real de navegação dos usuários.

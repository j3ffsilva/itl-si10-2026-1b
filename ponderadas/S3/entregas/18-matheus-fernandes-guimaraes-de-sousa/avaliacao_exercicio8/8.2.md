```text
def gerar_tempos_uniforme(objetivo, usou_busca, faixa_horaria):
    """Versão modificada: tempo de leitura com distribuição uniforme em vez de log-normal."""
    params_busca = {
        'buscar_sistema': (4.0, 0.55), 'buscar_documento': (4.0, 0.55),
        'buscar_pessoa': (4.0, 0.55), 'ler_comunicado': (2.9, 0.45),
        'acompanhar_noticias': (3.2, 0.50),
    }
    mu_b, sig_b = params_busca.get(objetivo, (3.5, 0.50))
    tempo_busca = np.random.lognormal(mu_b, sig_b)  # mantemos log-normal na busca

    # *** MODIFICAÇÃO: tempo de leitura agora é uniforme ***
    # Ajuste os limites para manter uma média similar
    lim_inf = 40
    lim_sup = 420 if objetivo in {'ler_comunicado', 'acompanhar_noticias'} else 180
    tempo_leitura = np.random.uniform(lim_inf, lim_sup)

    if not usou_busca:
        tempo_busca *= 0.45
    if faixa_horaria == '08-11':
        tempo_leitura *= 0.88
        tempo_busca   *= 1.08
    ruido = np.random.gamma(shape=2.0, scale=8.0)
    tempo_total = tempo_busca + tempo_leitura + ruido
    return tempo_busca, tempo_leitura, tempo_total
```

```text
A substituição da distribuição log-normal por uma distribuição uniforme reduz significativamente a presença de caudas longas no tempo de leitura. Isso torna os dados visualmente mais regulares, mas menos compatíveis com padrões reais de navegação humana.

Em comportamento digital, é esperado que existam muitas sessões curtas e poucas sessões muito longas. A distribuição uniforme reduz essa assimetria natural e tende a piorar métricas de fidelidade estatística relacionadas à aderência da distribuição original.

Mesmo assim, a coerência interna entre `tempo_leitura_segundos` e `clicou_comunicado` pode continuar parcialmente preservada, principalmente se usuários que clicam em comunicados ainda apresentarem tempos medianos maiores.

O exercício demonstra que melhorar uma dimensão específica da base não garante melhora global de qualidade. Em dados sintéticos, fidelidade estatística, coerência interna e adequação ao propósito precisam ser avaliadas em conjunto.
```

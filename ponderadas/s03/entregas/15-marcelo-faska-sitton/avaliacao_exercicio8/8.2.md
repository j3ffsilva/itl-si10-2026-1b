def gerar_tempos_uniforme(objetivo, usou_busca, faixa_horaria):
    """Versão modificada: tempo de leitura uniforme em vez de log-normal."""
    params_busca = {
        'buscar_sistema': (4.0, 0.55), 'buscar_documento': (4.0, 0.55),
        'buscar_pessoa': (4.0, 0.55), 'ler_comunicado': (2.9, 0.45),
        'acompanhar_noticias': (3.2, 0.50),
    }
    mu_b, sig_b = params_busca.get(objetivo, (3.5, 0.50))
    tempo_busca = np.random.lognormal(mu_b, sig_b)

    # *** MODIFICAÇÃO: tempo de leitura agora é uniforme ***
    lim_inf = 30
    lim_sup = 400 if objetivo in {'ler_comunicado', 'acompanhar_noticias'} else 200
    tempo_leitura = np.random.uniform(lim_inf, lim_sup)

    if not usou_busca:
        tempo_busca *= 0.45
    if faixa_horaria == '08-11':
        tempo_leitura *= 0.88
        tempo_busca   *= 1.08
    ruido = np.random.gamma(shape=2.0, scale=8.0)
    return tempo_busca, tempo_leitura, tempo_busca + tempo_leitura + ruido

def teste_aderencia_ks(serie, mu_teorico=3.5, sigma_teorico=0.5):
    """
    Kolmogorov-Smirnov contra log-normal TEÓRICA do E02 (não ajustada aos dados).

### Respostas às 3 perguntas

1. **Teste de aderência:** a estatística KS sobe quando trocamos log-normal por uniforme — a uniforme **não tem cauda direita** (não há sessões muito longas), o que produz um desvio claro da curva log-normal teórica do E02. **Fidelidade estatística piora.**

2. **Coerência interna:** a diferença de medianas entre quem clicou e quem não clicou **aumenta** na uniforme (+88s vs. +36s na original) e o Mann-Whitney continua significativo nos dois casos. **A direção da hipótese é preservada — e até amplificada artificialmente.**

3. **A base é melhor ou pior?** Depende do critério. **Pior em fidelidade**, **aparentemente melhor em "demonstrabilidade visual" do efeito comportamental**. É uma base mais fácil de explicar, e por isso mais perigosa — passa a sensação de evidência forte sem refletir a variância real do comportamento humano. Esse é o trade-off central: otimizar uma dimensão de qualidade não garante que as outras melhorem.

### Conexão com o mundo real

Esse trade-off entre fidelidade e coerência é algo que enfrentamos o tempo todo. Usar uma distribuição uniforme deixa o gráfico mais 'limpo' e o efeito comportamental mais óbvio para uma apresentação executiva, mas é uma armadilha. No IPT real, o tempo de leitura tem uma 'cauda longa': a maioria das pessoas lê rápido, mas existe um grupo (especialmente Pesquisadores) que mergulha fundo nos textos técnicos. Ignorar essa cauda é ignorar o comportamento de quem mais gera valor para o instituto.

Se usarmos essa base 'simplificada' para planejar o tamanho do Teste A/B, vamos acabar subestimando o volume de dados necessário. O resultado? O teste termina sem nos dar uma resposta clara. No Analytics do SharePoint, o dado real vai ser sempre bagunçado e assimétrico; por isso, nossa governança interna deve ser rígida: usamos a log-normal para cálculos sérios e deixamos as distribuições uniformes apenas para exemplos didáticos, sempre avisando o time sobre essa simplificação.

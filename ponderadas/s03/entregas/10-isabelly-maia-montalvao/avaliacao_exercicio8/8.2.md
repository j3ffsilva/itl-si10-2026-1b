def gerar_tempos_uniforme(objetivo, usou_busca, faixa_horaria):
    """Versão modificada: tempo de leitura com distribuição uniforme em vez de log-normal."""
    params_busca = {
        'buscar_sistema': (4.0, 0.55), 'buscar_documento': (4.0, 0.55),
        'buscar_pessoa': (4.0, 0.55), 'ler_comunicado': (2.9, 0.45),
        'acompanhar_noticias': (3.2, 0.50),
    }
    mu_b, sig_b = params_busca.get(objetivo, (3.5, 0.50))
    tempo_busca = np.random.lognormal(mu_b, sig_b)  # mantemos log-normal na busca

    # *** MODIFICAÇÃO: tempo de leitura agora é uniforme ***
    # Ajuste os limites para manter uma média similar
    lim_inf = 30
    lim_sup = 400 if objetivo in {'ler_comunicado', 'acompanhar_noticias'} else 200
    tempo_leitura = np.random.uniform(lim_inf, lim_sup)

    if not usou_busca:
        tempo_busca *= 0.45
    if faixa_horaria == '08-11':
        tempo_leitura *= 0.88
        tempo_busca   *= 1.08
    ruido = np.random.gamma(shape=2.0, scale=8.0)
    tempo_total = tempo_busca + tempo_leitura + ruido
    return tempo_busca, tempo_leitura, tempo_total

**Resposta — Exercício 8.2**

**1. O que acontece com o teste de aderência?**
A fidelidade estatística **piora**. A distribuição uniforme não tem a cauda direita assimétrica da log-normal, então qualquer teste qui-quadrado ou KS contra a distribuição teórica do E02 vai detectar um desvio muito maior. A âncora real do IPT — que tem cauda longa típica de tempo de leitura humano — fica violada.

**2. O que acontece com a coerência entre `tempo_leitura_segundos` e `clicou_comunicado`?**
Aparentemente *melhora*: a diferença mediana entre quem clicou e quem não clicou salta de **+36 s** (lognormal) para **+88 s** (uniforme). Mas isso é **artefato dos limites escolhidos** — `[30, 400]` para os objetivos de leitura vs `[30, 200]` para os demais —, não comportamento humano. Se eu mudasse os limites, a "coerência" mudaria com eles.

**3. A nova base é melhor ou pior?**
**Pior, no que importa.** Ela passa o teste de direção (ainda existe diferença entre os grupos), mas falha em fidelidade e introduz uma falsa sensação de coerência forte. Esse é o trade-off central do caderno: **otimizar uma dimensão de qualidade pode mascarar deterioração em outra**, e qualquer avaliação responsável precisa olhar o conjunto.

**Conclusão:** a base log-normal é defensável; a uniforme não é — porque, embora pareça preservar a hipótese comportamental, está apoiada em parâmetros arbitrários e perde o realismo distribucional que ancorava a base nos sinais reais do IPT.

    pesos = np.array(pesos, dtype=float)

def inserir_outliers_realistas(df):
    df = df.copy()
    idx_tempo = df.sample(frac=0.006, random_state=42).index
    fator_tempo = np.random.uniform(2.2, 4.0, len(idx_tempo))
    df.loc[idx_tempo, "tempo_leitura_segundos"] *= fator_tempo
    df.loc[idx_tempo, "tempo_total_segundos"] = (
        df.loc[idx_tempo, "tempo_busca_segundos"]
        + df.loc[idx_tempo, "tempo_leitura_segundos"]
        + np.random.uniform(10, 35, len(idx_tempo))
    )

    idx_pv = df.sample(frac=0.004, random_state=7).index
    df.loc[idx_pv, "pageviews"] += np.random.randint(8, 18, len(idx_pv))
    df.loc[idx_pv, "numero_interacoes"] = (
        df.loc[idx_pv, "pageviews"]
        + df.loc[idx_pv, "clicou_comunicado"]
        + df.loc[idx_pv, "clicou_link_operacional"]
        + df.loc[idx_pv, "usou_busca"]
    )

    df["proporcao_tempo_leitura"] = (df["tempo_leitura_segundos"] / df["tempo_total_segundos"]).round(4)
    df["abandono_rapido"] = (
        ((df["tempo_total_segundos"] < 35) & (df["pageviews"] <= 2))
        | ((df["sucesso_encontrou_o_que_queria"] == 0) & (df["tempo_total_segundos"] < 45))
    ).astype(int)
    return df

### Motivação

Tudo o que foi calculado no caderno principal partiu de **uma única realização** da base sintética (`seed = 42`). Isso é frágil por construção: se o seed mudasse, todas as métricas — desvios de pesos, p-valores, gaps de sucesso — também mudariam. A pergunta que surge naturalmente: **o veredito do scorecard é uma propriedade do gerador ou um acidente de um seed específico?**

**Por que isso importa.** Quando o time de comunicação do IPT receber a análise principal, eles podem (e devem) perguntar: *"e se vocês tivessem rodado de novo? a hipótese H3 ainda quebraria?"*. Se a resposta for "depende do seed", o argumento de adequação ao propósito enfraquece — o veredito vira uma observação pontual, não uma propriedade estrutural da base.

**O que fazemos a seguir.** Geramos a base com 30 seeds diferentes, computamos as métricas-chave de cada eixo do scorecard e medimos a variabilidade. O objetivo não é validar o gerador formalmente, mas responder em ordem de grandeza:

- A **direção** das relações de coerência se mantém em todos os seeds, ou existe uma fração que falha?
- O **desvio máximo de pesos por perfil** fica sempre dentro do limite de 2 pp, ou às vezes estoura?
- A hipótese **H3** (mobile com sucesso menor que desktop) é violada **em todos os seeds** — ou só em alguns? Se for só em alguns, a violação pode ser ruído amostral em um segmento de n pequeno (~130 sessões mobile).
- A **taxa de clique em comunicados** flutua dentro do que importaria para uma decisão de negócio?

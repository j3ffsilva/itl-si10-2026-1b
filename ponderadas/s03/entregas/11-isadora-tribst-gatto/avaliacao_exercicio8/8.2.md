def gerar_tempos_uniforme(objetivo, usou_busca, faixa_horaria):
    """Versão modificada: tempo de leitura com distribuição uniforme em vez de log-normal."""
    params_busca = {
        'buscar_sistema': (4.0, 0.55), 'buscar_documento': (4.0, 0.55),
        'buscar_pessoa': (4.0, 0.55), 'ler_comunicado': (2.9, 0.45),
        'acompanhar_noticias': (3.2, 0.50),
    }
    mu_b, sig_b = params_busca.get(objetivo, (3.5, 0.50))
    tempo_busca = np.random.lognormal(mu_b, sig_b)  # mantemos log-normal na busca

    # *** MODIFICAÇÃO: tempo de leitura agora é uniforme ***
    # Ajuste os limites para manter uma média similar
    lim_inf = 30
    lim_sup = 400 if objetivo in {'ler_comunicado', 'acompanhar_noticias'} else 200
    tempo_leitura = np.random.uniform(lim_inf, lim_sup)

    if not usou_busca:
        tempo_busca *= 0.45
    if faixa_horaria == '08-11':
        tempo_leitura *= 0.88
        tempo_busca   *= 1.08
    ruido = np.random.gamma(shape=2.0, scale=8.0)
    tempo_total = tempo_busca + tempo_leitura + ruido
    return tempo_busca, tempo_leitura, tempo_total

# Avaliação — Exercício 8.2

## 1. Teste de aderência em tempo_leitura_segundos
A distribuição uniforme diverge estruturalmente da log-normal original:
enquanto a log-normal concentra valores baixos e tem cauda longa, a uniforme
distribui todos os valores igualmente entre lim_inf e lim_sup.
Um teste de aderência detectaria desvio muito elevado — a fidelidade
estatística piora significativamente.

## 2. Coerência entre tempo_leitura_segundos e clicou_comunicado
- Base original (log-normal): Não clicou=26s | Clicou=61s | Diferença=+35s
- Base modificada (uniforme): Não clicou=114s | Clicou=203s | Diferença=+89s

A direção se mantém (quem clicou ainda tem mediana maior), mas os valores
absolutos são implausíveis para navegação web. A coerência direcional
sobrevive, mas a coerência de magnitude falha.

## 3. A nova base é melhor ou pior?
Pior, em fidelidade estatística (distribuição não representa o
comportamento real de leitura) e em plausibilidade de magnitude
(medianas de 114s e 203s são irrealistas). A coerência direcional
maior é um falso ganho: os valores absolutos perderam realismo.

Conclusão: trocar a distribuição sem justificativa comportamental
piora múltiplos eixos simultaneamente, mesmo que um indicador
isolado aparente melhora.

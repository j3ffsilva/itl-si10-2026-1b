# S3 - Exercicio 8

Esta pasta contem as entregas e a avaliacao final da ponderada de Geracao e Avaliacao de Dados Sinteticos.

## Arquivos principais

- `notas_exercicio8_finais.tsv`: tabela final de notas e feedbacks.
- `rubrica_exercicio8.md`: rubrica usada para atribuicao das notas.
- `entregas/`: notebooks, metadados e avaliacao final por estudante.
- `listagem-das-entregas.tsv`: listagem das entregas.
- `download_entregas.py`: script usado para baixar/organizar entregas.

## Avaliacoes por estudante

Cada pasta em `entregas/<estudante>/` contem uma subpasta `avaliacao_exercicio8/` com:

- `avaliacao.md`: nota final, feedback, evidencias e confianca.
- `8.1.md`, `8.2.md`, `8.3.md`: evidencias usadas para cada exercicio.

As notas finais devem considerar `notas_exercicio8_finais.tsv` e os arquivos `entregas/<estudante>/avaliacao_exercicio8/avaliacao.md`.
